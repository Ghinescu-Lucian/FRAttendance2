# TypeScript HTTPS Face Enrollment with Local Phone Embeddings

This version opens the phone camera, checks quality locally, asks for multiple poses, creates descriptors locally in the browser, and uploads one JSON embedding file to the same `images` folder.

## Important compatibility note

The JSON descriptors generated by this browser app are compatible with the same face-api recognition model/pipeline. They are not directly compatible with Python YuNet/SFace or InsightFace embeddings.

## Install

```powershell
npm install
```

## HTTPS certificate

```powershell
mkcert -install
mkcert -cert-file certs\local-cert.pem -key-file certs\local-key.pem YOUR_PC_WIFI_IP localhost 127.0.0.1
```

## Environment

```powershell
copy .env.example .env
```

## Run

```powershell
npm run dev
```

Open on phone:

```text
https://YOUR_PC_WIFI_IP:3000
```

## Disable image upload

In `src/public/app.ts`, set:

```ts
const UPLOAD_ACCEPTED_IMAGES = false;
```

Then only the single JSON embeddings file is uploaded.


## Filename format

Uploaded accepted images are saved without dates:

```text
GhinescuLucian_1.jpg
GhinescuLucian_2.jpg
GhinescuLucian_3.jpg
```

Uploaded embedding JSON files are saved as:

```text
GhinescuLucian_embeddings_1.json
GhinescuLucian_embeddings_2.json
```
